# Template lab

This directory is a static, generated comparison gallery for Sketcher's native
26-4 RDKit runtime. Serve it over HTTP, rather than opening `index.html` as a local
file. On GitHub Pages it is available at `/sketcher/template-gallery/`.

See [the generator documentation](../../tools/template_gallery/README.md) for
the source corpus, generation command, build provenance, comparison settings,
validation and limitations. Compressed per-template JSON contains the paired
SVGs and public molecule SMILES; `results.csv` contains the metrics.
